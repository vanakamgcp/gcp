ETL/ELT for Beginners – GCP Data Engineering Bootcamp

Slide 1: What is ETL/ELT?
--------------------------
ETL (Extract, Transform, Load)
- Extract: Pull data from different sources
- Transform: Clean, filter, format the data
- Load: Put the data into a data warehouse

ELT (Extract, Load, Transform)
- Extract: Pull data
- Load: Put raw data directly into warehouse
- Transform: Use SQL or tools to clean and shape it inside the warehouse

✅ Use ELT when working with modern cloud data warehouses like BigQuery

Slide 2: Key Terminologies
--------------------------
- Upstream – Source system or process that provides data (e.g., a database, file)
- Downstream – System or process that consumes data (e.g., dashboard, ML model)
- Pipeline – Series of steps to move and process data
- Data Ingestion – Bringing data into the system
- Data Transformation – Changing data into the desired format
- Data Quality Checks – Validating if data is correct and complete

Slide 3: Data Layers (Zones)
----------------------------
- Raw Layer – Unchanged, original data
- Curated Layer – Cleaned and standardized data
- Serving Layer – Ready-to-use data for dashboards, reports, ML

Also Known As:
- Bronze (Raw), Silver (Curated), Gold (Serving)

Slide 5: GCP-Based ETL/ELT Architecture (Batch Example)
-------------------------------------------------------
Cloud Storage → Cloud Function → BigQuery Staging Table → BigQuery Final Table
           (Extract)         (Transform)            (Load & Serve)

Tools:
- Cloud Storage – Store files (CSV, JSON, Parquet)
- Cloud Functions – Run transformation code
- BigQuery – Store and analyze data

Slide 6: Real-time Data Processing in GCP (ELT)
-----------------------------------------------
Pub/Sub → Dataflow → BigQuery
     (Streaming ingest)    (Transform)     (Store & Query)

- Pub/Sub – Capture real-time events
- Dataflow – Stream processing engine (Apache Beam)
- BigQuery – Store and serve insights

Slide 7: Why ELT is Popular in Cloud?
-------------------------------------
- BigQuery is fast and scalable
- SQL can be used for transformation
- Easy to schedule using Workflows or Composer
- Cheaper & simpler architecture

Slide 8: Common Use Cases
-------------------------
- Loading CSV files from Cloud Storage to BigQuery
- Ingesting real-time logs to BigQuery using Pub/Sub
- Transforming raw sales data to generate reports

Slide 9: Recap – ETL vs ELT
---------------------------
| Feature        | ETL                   | ELT                      |
|----------------|------------------------|--------------------------|
| Transform Step | Before Load            | After Load               |
| Speed          | Slower (depends on tool) | Faster with cloud tools  |
| Storage        | May need extra space   | Uses cloud data warehouse directly |
