The Name python is inspired the BBC's TV show "The MONDY's Python Circus"


Python is Intrepreter language.
High level programming language.
Human friendly.

Intrepreter Language-Executes line by line. Stop the execution when the first error occurs.

Compiler Language - Executes only with zero error codes.
